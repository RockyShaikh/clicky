# Test fixtures

`screens/` holds 25 **synthetic** mock app screenshots (1280x800 PNG, no real screen content) and `targets.json`
(`{file, question, target_box_px:[x1,y1,x2,y2], app_bundle_id, ...}`; origin top-left, screenshot pixels).
They are generated by `scripts/make-fixtures.mjs` (deterministic); target boxes are exact by construction.
Real-app screenshots can be added later as extra entries, but never screenshots of a personal screen.
